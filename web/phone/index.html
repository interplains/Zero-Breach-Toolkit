Want to check this computer itself?

A web page is not allowed to look at your computer's programs, start-up items or connections, which is also why nothing here can leave your device. To check the computer, use the free program: download Zero Breach. This page checks phone backups.

Open this page on a computer

A phone backup is made on, and stored on, a computer (Mac, Windows or Linux). Open this page on the computer that holds the backup, in Chrome, Edge, Firefox or Safari.

1Which phone?

2Make a backup

Connect the iPhone to the computer with a cable and unlock it. Tap Trust if it asks.

  1. Mac: open Finder and click the iPhone in the sidebar. Windows: open the Apple Devices app (or iTunes on older Windows).
  2. Choose Back up all of the data on your iPhone to this computer.
  3. Tick Encrypt local backup and set a password you will remember. Encrypted backups hold more of the records spyware leaves behind (website history, call records), so the check sees more.
  4. Click Back Up Now and wait until it finishes.
Where is the backup folder?

Mac: in Finder, click Manage Backups…, right-click the backup and choose Show in Finder. Copy that folder (a long name of letters and numbers) to your Desktop and choose the copy in step 3: macOS does not let browsers open the original location.

Windows (Apple Devices app): C:\Users\you\Apple\MobileSync\Backup
Windows (iTunes): C:\Users\you\AppData\Roaming\Apple Computer\MobileSync\Backup
You can paste that path into the folder window's address bar. Choosing the Backup folder itself is fine: if it holds several phones, this page asks which one.

Android has no built-in backup that is enough for this check. Make a collection with AndroidQF, the free tool from Amnesty International's Security Lab that the Zero Breach program also uses:

  1. Easiest: in the Zero Breach program choose A phone → Collect from an Android phone. It downloads AndroidQF, verifies it and guides you through each step.
  2. Or run AndroidQF yourself (github.com/mvt-project/androidqf): turn on USB debugging on the phone, connect it, run AndroidQF and follow its questions.
  3. If you get a .zip, unzip it first. Choose the folder that contains packages.json.

If the collection was encrypted with an age key, decrypt it first; this page reads plain folders only.
